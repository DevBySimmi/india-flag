Indian Flag Using Python

A simple Python project that creates the Indian National Flag 🇮🇳 using Matplotlib.

✨ Features

- 🇮🇳 Indian Tricolour
- 🟧 Saffron, white, and green sections
- 🔵 Ashoka Chakra in the center
- 🐍 Built with Python
- 📊 Uses Matplotlib for drawing
- 💻 Beginner-friendly project

🛠️ Requirements

Make sure you have Python 3.x installed.

Install Matplotlib using:

pip install matplotlib

🚀 How to Run

Clone the repository:

git clone https://github.com/your-username/india-flag-python.git

Open the project folder:

cd india-flag-python

Run the Python file:

python flag.py

📂 Project Structure

india-flag-python/

🖼️ Output

The program generates the Indian National Flag with the Ashoka Chakra in the center.

📚 Purpose

This project demonstrates how Python and Matplotlib can be used to create a simple graphical representation of the Indian National Flag.

It is a great beginner project for learning:

- Python
- Matplotlib
- Basic shapes
- Circles and lines
- Coordinate systems
- Graphical plotting
